Creating a consistent design system is essential for any team working on multiple projects. In this article, we'll explore how to build a modern design system using current CSS features.

## Why a Design System?

A design system provides a shared language for designers and developers. It ensures consistency across products and speeds up development.

## Getting Started

Start by defining your core tokens — colors, typography, spacing, and shadows. For a modern theme, we focus on:

- **Colors**: A cohesive palette with accent colors for interactions
- **Typography**: System font stack with clear hierarchy
- **Borders**: Subtle 1px borders with rounded corners
- **Spacing**: Consistent spacing scale (4px base)

## CSS Custom Properties

```css
:root {
  --color-accent: #2563EB;
  --color-bg: #FAFAF9;
  --font-sans: 'Inter', system-ui, sans-serif;
  --radius: 8px;
}
```

## Conclusion

A well-designed system reduces decision fatigue and creates visual harmony across your entire product suite.
