A Rust-based image processing library that compiles to WebAssembly for near-native performance in the browser.

## Features

- Real-time filter application
- Edge detection
- Color quantization
- Image resizing with Lanczos resampling

## Performance

Benchmark results show 10-20x speedup over pure JavaScript implementations for CPU-intensive operations.

## Tech Stack

- Rust (image processing core)
- wasm-bindgen (JS bindings)
- Web Workers (non-blocking execution)
- Canvas API (rendering)
