An exploration of electronic soundscapes combining retro synth wave with modern ambient production.

## Track List

1. Neon Drift
2. Midnight Circuit
3. Digital Rain
4. Solar Winds
5. Echoes

## Production

Built entirely in the browser using Web Audio API and Tone.js, with final mastering in Ableton Live.

## Technologies

- Tone.js for synthesis
- Web Audio API for processing
- Ableton Live for mixing
