A design system and UI component library that bridges retro gaming aesthetics with modern web usability.

## Components

- Buttons (6 variants)
- Form inputs
- Navigation elements
- Card layouts
- Modal dialogs
- Toast notifications

## Design Tokens

All tokens are defined as CSS custom properties for easy theming:

```css
--pixel-border: 2px solid var(--color-text);
--pixel-shadow: 4px 4px 0 var(--color-text);
--pixel-radius: 0px;
```

## Usage

The kit is designed to work with Tailwind CSS and can be imported as a set of utility classes.
