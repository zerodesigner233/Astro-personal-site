A lightweight JavaScript library for creating procedural art using Canvas 2D and WebGL.

## Algorithms

- Perlin noise flow fields
- Voronoi tessellation
- Reaction-diffusion systems
- Particle systems

## Example

```javascript
import { Engine } from './generative-engine';

const engine = new Engine(canvas, {
  algorithm: 'flow-field',
  palette: ['#2563EB', '#7C3AED', '#EC4899'],
  particles: 10000,
});

engine.start();
```
